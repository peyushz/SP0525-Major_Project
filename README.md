# SP0525-Major_Project
Reflectra

Reflectra is a mobile UI/UX design project focused on improving productivity and time management through a structured and intuitive digital experience. The application is designed to help users organize daily activities, track performance patterns, and maintain a consistent workflow in a simple and efficient way.

The core idea behind Reflectra is to provide users with clear insights into how they spend their time. By combining activity tracking, analytics, and motivational elements, the app helps users become more aware of their productivity habits and make better time management decisions.

The app includes features such as daily activity tracking, burnout risk analysis, mood vs productivity comparison, time goal setting, focus sessions, and a reward system to encourage consistency. These features work together to create a balanced and engaging productivity environment without overwhelming the user interface.

The user experience is built with a clean layout, minimal design system, and strong visual hierarchy to ensure smooth navigation across screens like Dashboard, Timeline, Focus Session, Analytics, and Profile.

This project was fully designed using Figma, including low-fidelity wireframes, high-fidelity UI screens, reusable components, and complete user flow structure.
